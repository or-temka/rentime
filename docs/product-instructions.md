# Инструкции товаров

Статьи — MDX-файлы в каталоге продукта:

```
src/entities/product/constants/products/<product-id>/instructions/
```

Картинки кладите в `public/images/products/<product-id>/instructions/`.

## Файлы и URL

| Файл | URL |
|------|-----|
| `index.mdx` | `/products/<id>/instructions` — главная (оглавление) |
| `start-using.mdx` | `/products/<id>/instructions/start-using` |

Имя файла (slug): только `a-z`, `0-9` и дефисы, например `full-wash`, `chemical-4`.

В начале каждого файла:

```md
---
title: Заголовок страницы
description: Краткое описание для SEO
---
```

## Разметка

```md
## Раздел
### Подраздел

Обычный абзац.

- пункт списка
1. нумерованный

> Важное замечание (цитата)

![рис. 1. Подпись](/images/products/<id>/instructions/photo.webp)

[Другая статья](./start-using)
[Раздел на этой странице](#начало-работы)
[Раздел в другой статье](./full-wash#ополаскивание-поверхности)
```

`##` / `###` сами получают якорь из текста заголовка (пробелы и знаки → `-`).

## Ссылки на текст и картинки

**Текст** — оберните фрагмент в `Anchor` и ссылайтесь на его `id`:

```mdx
Залейте воду в <Anchor id="бак">основной бак</Anchor>.

См. [бак](#бак).
```

При переходе текст кратко подсвечивается зелёным; страница скроллит так, чтобы фрагмент был ближе к середине экрана.

**Картинка** — якорь из `alt` (тот же slugify):

```md
![рис. 7 - Переносите только за ручку](/images/products/.../start-using-7.webp)

[(рис. 7)](#рис-7-переносите-только-за-ручку)
```

Или короткий явный `id`:

```mdx
<img
  id="рис-7"
  src="/images/products/.../start-using-7.webp"
  alt="рис. 7 - Переносите только за ручку"
/>

[(рис. 7)](#рис-7)
```

Ссылка на ту же статью (`#...`) не перезагружает страницу.

## Оглавление товара

В `index.mdx` обычно список ссылок на статьи:

```md
## Основное

- [Как пользоваться](./start-using)
- [Полная мойка](./full-wash)
```
